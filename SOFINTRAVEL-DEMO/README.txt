SOFINTRAVEL

Как запустить сайт:

1. Распакуйте архив.
2. Откройте папку SOFINTRAVEL-DEMO.
3. Дважды нажмите «Start SOFINTRAVEL.bat».
4. Сайт автоматически откроется в браузере.

Для завершения работы дважды нажмите «Stop SOFINTRAVEL.bat».

Никакие программы устанавливать не нужно.

Если браузер не открылся автоматически, откройте адрес:
http://127.0.0.1:4173

Сайт и презентация доступны без интернета.
